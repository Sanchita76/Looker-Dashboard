# Project 4 - Looker Studio Dashboard (Online Retail data from Kaggle)

**Dataset:** *E-Commerce Data* (`carrie1/ecommerce-data`) - the UCI "Online Retail" transactions of a UK gift retailer:
541,909 invoice lines, Dec 2010 - Dec 2011, 38 countries, cancellations (negative quantities), guest checkouts, non-product
stock codes - real messy data that needs cleaning.

> **Honest note:** Looker Studio dashboards are built in the browser UI (there is no file format that can be generated by code).
> This project does the heavy work for you - **download, cleaning, RFM customer segmentation, calculated-field formulas,
> and a chart-by-chart layout** - and you assemble the charts in ~45-60 minutes.

```
04-looker-studio-retail/
├── requirements.txt
├── scripts/
│   ├── download_data.py        # Kaggle download
│   ├── make_demo_data.py       # fake data, same format (offline testing)
│   ├── prepare_data.py         # cleaning + RFM -> data/processed/*.csv
│   └── upload_to_bigquery.py   # optional BigQuery loader
├── looker/
│   ├── calculated_fields.md    # every metric/dimension formula to paste
│   └── dashboard_layout.md     # 3 pages, chart by chart
└── data/raw, data/processed    # demo data included
```
Outputs: `retail_clean.csv` (main fact file), `rfm_customers.csv` (customer segments: Champions, Loyal, At Risk...),
`product_summary.csv`.

## 1. Install (one time)
* **Python 3.9+** (https://www.python.org/downloads, tick "Add Python to PATH"), then `pip install -r requirements.txt`
* A free **Google account** (Looker Studio: https://lookerstudio.google.com)

## 2. Get and clean the data
**Option A - Kaggle (real data):** open https://www.kaggle.com/datasets/carrie1/ecommerce-data, click **Download**, unzip
`data.csv` into `data/raw/`. *(Automated: Kaggle -> Settings -> API -> Create New Token -> save `kaggle.json` to
`C:\Users\<you>\.kaggle\` or `~/.kaggle/`, then `python scripts/download_data.py`.)*
**Option B - demo data:** `python scripts/make_demo_data.py` (already included).

```bash
python scripts/prepare_data.py
```
What the cleaning does: fixes the ISO-8859-1 encoding, removes duplicates and zero-price rows, flags cancellations
(`C...` invoices), guest orders, and non-product codes (POST, D, M...), calculates `revenue`, adds date/hour/weekday fields,
and computes **RFM scores** per customer (recency, frequency, monetary quintiles -> segment).

## 3. Connect the data to Looker Studio
1. Go to https://lookerstudio.google.com -> **Create -> Report**.
2. Choose connector **File Upload** -> upload `data/processed/retail_clean.csv` (~45 MB for the real data; limit is 100 MB) -> Add.
   (Wait for upload to finish. Alternatively use *Google Sheets* for smaller files, or BigQuery - see below.)
3. Click **Add data** -> File Upload again for `rfm_customers.csv` and `product_summary.csv`.
4. Open `looker/calculated_fields.md` and set field types + create the calculated fields.
5. Build the pages with `looker/dashboard_layout.md`.
6. Rename the report, then **Share** -> get link / schedule emails.

*Optional BigQuery route (scales better, refreshable):* `pip install google-cloud-bigquery pyarrow`, `gcloud auth application-default login`,
`python scripts/upload_to_bigquery.py --project YOUR_PROJECT --dataset retail`, then **Add data -> BigQuery**.

## 4. Questions the dashboard answers
* What are sales, orders, AOV and cancellation rate by month and country?
* Which products and time-of-day/weekday drive revenue?
* Who are the best customers (RFM Champions) vs "At Risk"/"Lost" customers, and how much revenue does each segment bring?

## Troubleshooting
| Problem | Fix |
|---|---|
| `UnicodeDecodeError` | you opened/saved the raw CSV in Excel - re-download; the script reads ISO-8859-1 |
| Upload fails: file too large | the real `retail_clean.csv` should be <100 MB; if not, delete columns or use BigQuery |
| Dates show as text | set `invoice_date` type to Date (YYYYMMDD) in the data source editor |
| Map is blank | set `country` type to Geo -> Country |
| Blended chart shows nothing | join key `customer_id` must be Text in both sources |
